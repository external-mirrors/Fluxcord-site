This guide sets your server up for bridging to Fluxer.

<Aside>If you're self hosting, go to the [Self-hosting guide](/self-hosting).</Aside>

<Steps>

1. Firstly, you need to invite the bot on both sides.

   <LinkButton
    href="https://web.fluxer.app/oauth2/authorize?client_id=1500355990246776845&scope=bot&permissions=2260735261797440"
    icon="fluxer"
    iconPlacement="start"
   >
    Invite on Fluxer
   </LinkButton> <LinkButton
    href="https://discord.com/oauth2/authorize?client_id=1485825852489994423"
    icon="discord"
    iconPlacement="start"
   >
    Invite on Discord
   </LinkButton>

2. On the channel you want to bridge, run `fc!setup`.

3. Fluxcord should reply to you with a command to put on the other side. Copy it and send it on the other side.

4. Congratulations, your Discord channel is now bridged!

</Steps>
