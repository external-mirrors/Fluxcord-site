This guide sets your server up for bridging to Fluxer.

<Aside>If you're self hosting, go to the [Self-hosting guide](/self-hosting).</Aside>

<Steps>

1. Firstly, you need to invite the bot on both sides.
   <LinkButton
    href="https://web.fluxer.app/oauth2/authorize?client_id=1474209901993570338&scope=bot&permissions=2260735261797440"
    icon="fluxer"
    iconPlacement="start"
   >
    Invite on Fluxer
   </LinkButton> <LinkButton
    href="https://discord.com/oauth2/authorize?client_id=1485825852489994423"
    icon="discord"
    iconPlacement="start"
   >
    Invite on Discord
   </LinkButton>

   <Aside type="note">
   In other Fluxer instances (aka not fluxer.app), there are currently a flagship instance on these instances:
   ##### Fluxcord on FluxFur - prefix: `fcfur!`
   <LinkButton
    href="https://fluxfur.com/oauth2/authorize?client_id=1543969894750486528&scope=bot&permissions=2260735261797440"
    icon="fluxfur"
    iconPlacement="start"
   >
    Invite on FluxFur
   </LinkButton> <LinkButton
    href="https://discord.com/oauth2/authorize?client_id=1543968881599848629"
    icon="discord"
    iconPlacement="start"
   >
    Invite on Discord
   </LinkButton>
   </Aside>

2. On the channel you want to bridge, run `fc!setup`.
   <Aside type="note">
   Change `fc!` to your instance's prefix if `fc!` did not work (e.g. if you're using Fluxcord on FluxFur, use `fcfur!bridge setup`)
   </Aside>

3. Fluxcord should reply to you with a command to put on the other side. Copy it and send it on the other side.

 4. Congratulations, your Discord channel is now bridged!

 </Steps>

 ## Bridging a voice channel
 <Steps>

 1. Firstly, run `fc!bridge setup` on the voice channel you want to bridge, on either side.
    <Aside type="note">
    Change `fc!` to your instance's prefix if `fc!` did not work (e.g. if you're using Fluxcord on FluxFur, use `fcfur!bridge setup`)
    </Aside>

 2. Fluxcord should reply to you with a command to put on the other side. Copy it and send it on the voice channel you want to bridge to.

 3. Congratulations, your voice channel is now bridged! Join either side and you should hear the other side.
      <Aside type="note">
      If you think your server usually have multiple voice channels active at the same time, you can invite
