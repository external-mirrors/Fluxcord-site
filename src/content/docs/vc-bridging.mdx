<Aside type="danger" title="Important Notes">
  Please note that:
  - Fluxer does not currently support end-to-end voice encryption,
    that means Fluxcord will bridge your Discord VC **unencrypted**.
  - Aside from that above, to be able for Fluxcord to bridge voice data,
    **it will decrypt** DAVE-encoded data to be sent to Fluxer. We cannot change this.
    If you're using a Fluxcord instance other than the flagship, please make sure
    you trust the hoster of the instance, even though Fluxcord will **never** save
    voice data on disk (and processes it in real time).
  - There are things that Fluxcord will not bridge, such as:
    - Discord activities
    - Go Live screen shares
    - Per-user Voice Statuses ("Chilling", etc)
  - There are limitations of bridging voice, the most impactful part
    is that the other side will **not** know who joins the other side.
  - To bridge Discord VC chats, use `fc!setup`. Fluxer does not currently have VC chats,
    which means you need to bridge it to a normal channel on Fluxer.

  **Please make sure you have discussed this clearly to your server members,
  and add a easy-to-find disclaimer about the bridge.**
  Failing to note this in most jurisdictions, might violate privacy regulations.
  
  <small>Fluxcord is **not liable** on any damages caused by miscommunication.
  Note that we are not lawyers.</small>
</Aside>

<Aside type="tip">
  Voice bridging is separate to the main bot, which means you can run voice bridging
  independently. Important notes are still there, but you can be sure that you trust
  the one that hosts the bot (you) with voice data. This is also useful for one-off
  cases (e.g. one-time events), or for integrating Fluxcord's voice features to other
  services/bots.

  If you want to do it, check fluxcord/voice's repository. API documentation will come soon.
</Aside>
